# Migrar desde Additio

Additio es una plataforma web con apps nativas para iOS/Android. Teacher Brain se enfoca más en profesorado individual de FP mientras que Additio cubre también gestión de centros.

## ¿Qué ganas?

| Característica | Additio | Teacher Brain |
|---------------|---------|---------------|
| Trazabilidad RA/CE | Parcial (LOMLOE) | Nativa y completa |
| Tutoría con privacidad | No | Sí (4 niveles) |
| FCT/FFE | No | Sí |
| Precio | Freemium / Planes | Gratuito (fase actual) |
| PWA offline | No | Planificado |
| Magic BOE Import | No | Planificado |

## Cómo migrar

1. **Exporta desde Additio**: usa la exportación CSV/XLS de Additio para alumnado y calificaciones.
2. **Crea tu cuenta** en Teacher Brain y completa el onboarding.
3. **Importa alumnado** desde el CSV exportado.
4. **Recrea RAs, CEs y actividades**. El Magic BOE Import automatizará parte de este proceso.

## Diferencias clave

- Additio está más orientado a centros educativos completos. Teacher Brain se enfoca en el profesor individual de FP.
- Additio tiene apps nativas. Teacher Brain es 100% web con PWA offline planificada.
- Additio tiene marketplace de recursos (Additiopedia). Teacher Brain planea un marketplace de rúbricas entre profesores.
